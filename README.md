# رزومه تعاملی (تک‌صفحه)

این پروژه یک سایت رزومه تعاملی است که با اسکرول کنترل می‌شود و تمام انیمیشن‌ها کدنویسی شده‌اند.

## استک

- HTML5
- CSS3
- JavaScript ماژولار
- GSAP + ScrollTrigger
- Lenis (اسکرول نرم)

## ساختار اصلی

- `index.html`
- `assets/css/main.css`
- `assets/js/app.js`
- `assets/js/modules/smooth-scroll.js`
- `assets/js/modules/navigation.js`
- `assets/js/modules/ui-interactions.js`
- `assets/js/modules/topics-physics.js`
- `assets/js/modules/tips-stack.js`
- `assets/js/modules/scroll-animations.js`

## سکانس‌های صفحه

1. Hero
2. Topics (انیمیشن توپ‌های مهارت)
3. Tips Stack
4. Learning
5. Pills
6. Keyhole
7. Footer (ارتباط با ما)
